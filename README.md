# wx

A rudimentary Weather Star III/Jr simulator.

## Usage

* <kbd>c</kbd>: Toggle date and time shown on crawl
* <kbd>Esc</kbd>: Quit

## Dependencies

* C++23 compiler (build-time)
* Meson (build-time)
* Python 3 (build-time)
* SDL3
* SDL3_ttf

## Building

```
meson setup build
ninja -C build
```
